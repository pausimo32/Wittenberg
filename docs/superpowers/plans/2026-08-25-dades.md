# `/dades` — supplying the labelled database — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `/dades`, the browser surface that takes a lab session from an empty form to
rows in `data/metadata.csv`, without anyone copying a folder or editing a CSV by hand.

**Architecture:** A session in progress is a **draft** — a directory under `drafts/<session_id>/`
at the repo root, outside `data/`, holding the raw bytes exactly as they were uploaded, the
calibration, and one gate verdict per frame. Nothing under `data/` is touched until the user
presses commit. Committing *moves* the draft's `raw/` tree into `data/raw/<session_id>/` and then
calls `ingest.ingest_session` — the same function `python tasks.py ingest` calls. The live gate
that runs as each photo arrives calls `ingest.gate_frame`, the same verdict ingest will reach for
later. Draft state lives on the server, keyed by `session_id`, so a reload, a new tab or a pasted
link finds the session where it was.

**Tech Stack:** FastAPI (router mounted on the existing app), `src/ingest.py`, `src/quality.py`,
`src/calibrate.py`, `src/split.py`, `src/imageio.py`, OpenCV; Vite + React 19 + TypeScript +
Tailwind 4, React Router 7, vitest + Testing Library.

**Spec:** `docs/05-webapp-spec.md` §9 (the flow, the non-negotiable rules, the four acceptance
tests), `docs/02-dataset-spec.md` §4 (layout, `session.json`, `metadata.csv`), §6 (the gate),
§1.1 (the marker convention), `docs/adr/0004`, `docs/adr/0005`.

## Global Constraints

- `src/preprocess.py` is called by both training and the app and is **never forked**. Any edit to
  a transform requires updating `docs/03-preprocessing-spec.md` in the same commit and bumping the
  version. This round changes **no** transform.
- **No blocking call anywhere** — no `cv2.imshow`, no `plt.show()`, and no request handler that
  holds the event loop while it decodes 600 photos.
- **Never split the dataset randomly.** The split is by `session_id`, via `src/split.py`.
- **Never commit** `data/raw/`, `data/processed/`, `runs/`, `*.pt`, `*.pth`, `web/dist/` — and, new
  in this round, `drafts/`.
- **Deterministic by default.** Seed 42 everywhere. `split_dataset` already carries `SEED = 42`;
  this round adds no new randomness.
- **UI strings are Catalan; code, comments, commit messages and docs are English.** A term that is
  not in `docs/07-glossary-ca-en.md` gets added there *first*, in the same commit, and then used.
  No Catalan prose in Python: the API returns structured data and error codes, `web/src/strings.ts`
  turns them into sentences.
- **Native Windows, no `make`, no symlinks.** The task runner is `python tasks.py <target>`.
- **`127.0.0.1` only, no CORS, no outbound call of any kind.**
- Prefer `pathlib`; never hard-code `/` separators.
- Python 3.11, `opencv-contrib-python` 4.12, PyTorch on CPU.

## The five requirements, and where each is enforced

| # | Requirement | Enforced by | Proved by |
|---|---|---|---|
| 1 | Raw bytes arrive raw | `drafts.store_frame` writes `data` verbatim; previews are built from the *stored file* | `test_drafts.py::test_stored_bytes_are_the_uploaded_bytes` (SHA-256), `drafts.test.ts::sends the file's bytes unmodified` |
| 2 | A draft survives a reload | draft state is `drafts/<session_id>/draft.json`, not React state; `GET /api/drafts` lists them with id and path; `DELETE` discards | `test_dataset_api.py::test_draft_survives_a_new_client`, `Dades.test.tsx::lists open drafts with their path` |
| 3 | Calibration first, and the order is imposed | `POST /frames` returns 409 `not_calibrated` unless `calibration.ok` (4 markers found) | `test_dataset_api.py::test_frames_refused_before_calibration` |
| 4 | An existing `session_id` is a warning, not a silent replacement | `POST /commit` returns 409 `session_exists` with the row count unless `replace=true` | `test_dataset_api.py::test_commit_refuses_an_existing_session_without_replace` |
| 5 | Six hundred files are not six | uploads stream one verdict at a time through a bounded queue; commit runs in a thread with `progress(done, total)` polled by the UI | `test_dataset_api.py::test_commit_reports_progress`, `test_ingest.py::test_progress_is_called_once_per_frame` |
| 6 | A failed ingest leaves the draft or the session, never a third thing | the captures are staged at `data/raw/.incoming-<session_id>/`, ingested there, and renamed to the session name only once ingest returns | `test_drafts.py::test_a_failed_ingest_leaves_no_session`, `test_dataset_api.py::test_a_failed_commit_can_be_resumed` |
| 7 | The path boundary is its own check | `drafts._within` resolves every path built from a `draft_id` and refuses one that escapes the drafts root — separately from `validate_session_id`'s format rule | `test_drafts.py::test_a_traversal_id_is_refused_by_the_path_check_itself` |
| 8 | The same photo twice is not two observations | `store_frame` refuses a SHA-256 already in the draft and records it as a duplicate — a third counter, neither accepted nor rejected | `test_drafts.py::test_the_same_bytes_under_a_new_name_are_a_duplicate` |
| 9 | You can tell which draft to delete | the listing carries each draft's size on disk | `test_dataset_api.py::test_the_listing_carries_the_size_on_disk` |

## How this is executed

Hybrid, with one integrator holding the whole round. The split is not by task size — it is by
**where the errors live in each mode**.

Inline, the context fills: by task 14 the decisions of task 3 have been compacted away and the
integrator starts contradicting itself without noticing. By subagent, every task comes out clean
but nobody sees the seam — and in `/dades` the seam *is* the product: the draft store, the gate
and ingest have to meet exactly, and that is precisely where a reasonable change to one piece
breaks a property of another.

**Subagent** for a task whose contract fits in a paragraph and whose tests can be written before
its code. **Inline** for a task that crosses the draft ↔ gate ↔ ingest boundary. When in doubt,
inline: being wrong that way costs time, being wrong the other way costs a property.

| Batch | Tasks | Mode |
|---|---|---|
| 1 — the store | 1, 3, 5 | **inline** — ingest's own functions, the store's contract, the staging boundary |
| | 2, 4 | subagent |
| 2 — the API | 8, 9 | **inline** — store + gate + ingest meet in these two routes |
| | 6, 7, 10 | subagent |
| 3 — the view | 11, 12, 13, 14, 15, 16, 17 | subagent |
| 4 — closing | 18 | **inline** |

Two rules above that split:

- **Review every subagent's diff before its commit.** A subagent that passes its own tests may
  have relaxed an invariant those tests do not cover, because it did not know about it.
- **Run the whole suite between batches**, not just the task's tests. 441 and rising; the value is
  exactly that they catch what the task was not looking at.

And before the final commit, run `wittenberg-dataset-curator` over the dataset one commit produced.
The ingest skill says to run it after every ingest, and `/dades` is an ingest path — the first that
does not go through the command line.

```python
class Assessment(NamedTuple):
    """What one frame produced. `stages` and `decoded` are `None` unless asked for.

    `keep_stages` and `keep_input` exist for `/dades`'s live gate, which has to draw the
    rejection it is reporting. Both default to off, so ingest's own path costs exactly what
    it cost before: a rejected frame is not preprocessed, and a 48 MB RGBA array is never
    carried back out of a worker process.
    """

    result: GateResult | None
    stages: Any | None
    decoded: Any | None


def assess_frame(
    image_path: Path, calib, roi_mode: str, config, gate,
    *, keep_stages: bool = False, keep_input: bool = False,
) -> Assessment:
    """Decode, count markers, gate. See `Assessment` for the two optional returns."""
    try:
        decoded = decode(image_path)
    except UnsupportedImageError:
        return Assessment(None, None, None)

    n_markers = len(detect_markers(decoded.pixels)) if roi_mode == ROI_MODE_HOMOGRAPHY else 0
    result = assess(decoded.pixels, calib, n_markers=n_markers, config=config, gate=gate)

    # A `partial` frame has no usable ROI, so there are no stages to compute for it at all.
    wanted = result.accepted or (keep_stages and result.reason != "partial")
    stages = preprocess_stages(decoded.pixels, calib, config) if wanted else None
    return Assessment(result, stages, decoded if keep_input else None)


def gate_frame(image_path: Path, calib, roi_mode: str, config, gate):
    """The verdict `tasks.py ingest` will record for this frame, available before it runs.

    `/dades` calls this and nothing else. `docs/05` §9: "It is a different interface to one
    implementation, not a second one."
    """
    return verdict_of(assess_frame(image_path, calib, roi_mode, config, gate).result)
```

```python
def _assess_all(frames, calib, roi_mode: str, config, gate, jobs: int | None, progress=None):
    """... (keep the existing docstring, then add:)

    `progress(done, total)` is called after each frame, in input order, on the calling thread.
    It observes and never decides: the frame list, the order and every byte written are the
    same whether it is given or not, which `test_progress_does_not_change_a_single_byte`
    asserts.
    """
    if not frames:
        return []

    _init_worker(calib, roi_mode, config, gate)
    paths = [str(path) for _freq, path in frames]
    total = len(paths)

    def report(done: int) -> None:
        if progress is not None:
            progress(done, total)

    started = time.perf_counter()
    first = _assess_worker(paths[0])
    seconds_per_frame = time.perf_counter() - started
    report(1)
    rest = paths[1:]

    def serially():
        results = [first]
        for path in rest:
            results.append(_assess_worker(path))
            report(len(results))
        return results

    explicit = jobs is not None
    workers = max(1, int(jobs)) if explicit else worker_count()
    if not rest or workers == 1:
        return serially()
    if not explicit and not is_worth_parallelising(len(rest), seconds_per_frame):
        return serially()

    try:
        with ProcessPoolExecutor(
            max_workers=workers,
            initializer=_init_worker,
            initargs=(calib, roi_mode, config, gate),
        ) as pool:
            results = [first]
            for result in pool.map(_assess_worker, rest, chunksize=4):
                results.append(result)
                report(len(results))
            return results
    except (OSError, RuntimeError) as exc:        # BrokenProcessPool, no spawn, sandbox, ...
        print(
            f"  NOTE: the worker pool did not start ({type(exc).__name__}); finishing in one\n"
            f"        process, which is slower but identical. If this ran from a script, it\n"
            f"        needs an `if __name__ == \"__main__\":` guard."
        )
        return serially()
```

```python
"""A capture session in progress — `docs/05-webapp-spec.md` §9, steps 1 to 5.

**Why this lives outside `data/`.** §9: "Nothing is written until step 5. Uploading is not
committing. A half-finished session leaves no trace in `data/`." A draft directory under
`data/` would make that a promise kept by careful cleanup — one `except` away from being
false. `drafts/<session_id>/` makes it a property of the layout: abandoning a draft cannot
leave a trace in `data/` because nothing was ever written there.

It is the repo root and not the system temp directory on purpose. A draft is a lab afternoon;
an orphan afternoon in `%TEMP%` that nobody can find is indistinguishable from a lost one. The
path is listed by `GET /api/drafts` and shown in the view.

It is on the same volume as `data/` on purpose too: committing a draft *moves* its `raw/` tree
rather than copying it, so six hundred 12 MP captures change directory in milliseconds instead
of being read and rewritten.

The session log is validated here by `ingest.read_session_log` — the function that will refuse
the session at commit time. Validating the form with a second, friendlier copy of those rules is
how a form comes to accept a session that ingest then rejects.
"""

from __future__ import annotations

import json
import shutil
from dataclasses import dataclass
from datetime import datetime
from pathlib import Path
from typing import Any, Mapping

from ingest import SESSION_LOG, read_session_log
from metadata import validate_session_id

#: Repo root / drafts. Ignored by git; never inside `data/`.
DRAFTS_ROOT = Path(__file__).resolve().parents[1] / "drafts"

DRAFT_LOG = "draft.json"

STATUS_NEW = "new"
STATUS_CALIBRATED = "calibrated"
STATUS_COMMITTING = "committing"


class DraftError(ValueError):
    """The draft cannot do that."""


class DraftConflict(DraftError):
    """The draft cannot do that *because of state the user can see and decide about*."""


@dataclass(frozen=True)
class Draft:
    draft_id: str
    root: Path
    log: dict[str, Any]

    @property
    def session_id(self) -> str:
        return str(self.log["session_id"])

    @property
    def status(self) -> str:
        return str(self.log.get("status", STATUS_NEW))

    @property
    def raw(self) -> Path:
        """Mirrors `data/raw/<session_id>/` exactly, so committing is a directory move."""
        return self.root / "raw"

    @property
    def session(self) -> dict[str, Any]:
        return json.loads((self.root / SESSION_LOG).read_text("utf-8"))


def create(drafts_root: Path | str, session_log: Mapping[str, Any]) -> Draft:
    """Start a draft. The session log is written first and validated immediately."""
    session_id = validate_session_id(str(session_log.get("session_id", "")))
    root = _within(drafts_root, session_id)
    if root.exists():
        raise DraftConflict(
            f"a draft for session {session_id} is already open at {root} — open it or "
            f"discard it, rather than starting a second one for the same session"
        )

    root.mkdir(parents=True)
    (root / SESSION_LOG).write_text(
        json.dumps(dict(session_log), indent=2, ensure_ascii=False), "utf-8"
    )
    try:
        read_session_log(root, session_id)
    except Exception:
        # A draft that ingest would refuse is not a draft. Leave nothing behind.
        shutil.rmtree(root, ignore_errors=True)
        raise

    now = _stamp()
    return save(
        Draft(
            session_id,
            root,
            {
                "draft_id": session_id,
                "session_id": session_id,
                "status": STATUS_NEW,
                "created": now,
                "updated": now,
                "calibration": None,
            },
        )
    )


def save(draft: Draft) -> Draft:
    draft.log["updated"] = _stamp()
    (draft.root / DRAFT_LOG).write_text(
        json.dumps(draft.log, indent=2, ensure_ascii=False), "utf-8"
    )
    return draft


def listing(drafts_root: Path | str) -> list[Draft]:
    root = Path(drafts_root)
    if not root.is_dir():
        return []
    found = []
    for child in sorted(root.iterdir(), key=lambda p: p.name):
        if (child / DRAFT_LOG).is_file():
            found.append(read(root, child.name))
    return found


def read(drafts_root: Path | str, draft_id: str) -> Draft:
    root = _within(drafts_root, draft_id)
    path = root / DRAFT_LOG
    if not path.is_file():
        raise DraftError(f"no draft at {root}")
    return Draft(root.name, root, json.loads(path.read_text("utf-8")))


def discard(drafts_root: Path | str, draft_id: str) -> None:
    """Delete the draft and everything in it.

    `data/` is not touched, because nothing of this draft was ever in `data/`.
    """
    shutil.rmtree(_within(drafts_root, draft_id), ignore_errors=True)


def _within(drafts_root: Path | str, draft_id: str) -> Path:
    """The draft's directory, checked to be inside `drafts_root`. The boundary, said out loud.

    `validate_session_id` already refuses `../escape`, and today that is enough — but it refuses
    it for being a malformed *session id*, not for being a path. The day someone wants a
    friendlier identifier they will relax that format rule, and they will have no way to know
    they were also holding a path boundary shut. Three lines here keep the two intentions
    separable, so the next person cannot break one by touching the other.
    """
    root = Path(drafts_root).resolve()
    candidate = (root / str(draft_id)).resolve()
    if candidate != root and root not in candidate.parents:
        raise DraftError(f"{draft_id!r} does not name a directory inside {root}")
    return candidate


def _stamp() -> str:
    return datetime.now().isoformat(timespec="seconds")
```

Note that `create` still calls `validate_session_id` and `read`/`discard` still go through
`_within`: the two checks answer different questions and both are wanted. `validate_session_id`
says "this is a session id `docs/02` §2 recognises"; `_within` says "this path is inside the
drafts directory". A single check that happened to do both is a single check that can lose one.

`root not in candidate.parents` is the containment test rather than a string `startswith`, which
would accept `drafts-other/` as being inside `drafts/`.

```python
def thumbnail(image: np.ndarray, max_side: int) -> np.ndarray:
    """A display copy with its longest side capped. Never returned to the pipeline.

    One implementation, because there are now two callers — the pipeline viewer's stage 1 and
    `/dades`'s rejection thumbnails — and a resize that differs between them is a difference
    nobody would ever see reported.
    """
    height, width = image.shape[:2]
    longest = max(height, width)
    if longest <= max_side:
        return image
    scale = max_side / longest
    return cv2.resize(
        image, (max(1, round(width * scale)), max(1, round(height * scale))),
        interpolation=cv2.INTER_AREA,
    )
```

```python
#: Rejection thumbnails, not a gallery: they exist so someone can see *why* photo three failed
#: without leaving the view. 320 px is enough to see that the plate is out of frame or that the
#: pattern is smeared, and 600 of them cost nothing.
PREVIEW_MAX_SIDE = 320

FRAMES_LOG = "frames.json"
DUPLICATES_LOG = "duplicates.json"

#: A frame whose bytes are on disk but whose verdict has not come back yet. It is a real state,
#: not a placeholder: the upload and the gate are two steps of one request, and a frame that
#: never reached the second one must be visible as something rather than as nothing.
QUALITY_PENDING = "pending"

#: `frames.json` is a read-modify-write and the upload route runs in Starlette's thread pool
#: with three uploads in flight. Without this, two frames stored in the same instant read the
#: same log, and the second write drops the first — silently, and in exactly the situation the
#: whole view exists for. One process, one lock; it is held for a file write and a JSON dump,
#: never across the 560 ms decode.
_LOG_LOCK = threading.Lock()


class DraftDuplicate(DraftConflict):
    """This frame is already in the draft."""


class DuplicateName(DraftDuplicate):
    """Same filename, same class — the folder was dropped twice."""


class DuplicateContent(DraftDuplicate):
    """Same bytes as a frame already in the draft, under any name, in any class."""


def store_frame(draft: Draft, freq_hz: int, filename: str, data: bytes) -> dict[str, Any]:
    """Write one upload to the draft, **byte for byte**.

    The bytes are not decoded, re-encoded, rotated, stripped of EXIF or resized on the way in.
    `docs/02` §4 calls `data/raw/` "untouched, straight off the phone", and a draft is what
    becomes `data/raw/`. Every preview this module writes is generated from the file *after*
    it has been written, so the picture on screen can never be evidence about bytes that were
    not stored.

    The stored name is `IMG_<nnnn><ext>` by arrival order within the class, because ingest
    derives `image_id` from the trailing number of the stem (`docs/02` §4) and two phones will
    happily both produce `IMG_0001`. The name the file arrived with is kept in the record.

    **The same bytes are refused, whatever they are called.** Six hundred uploads over a
    connection that stumbles means someone retries a batch. A repeated frame trips no threshold
    and quietly unbalances the classes, and with a burst whose frames are already near-identical
    to each other, nobody is going to catch it by looking. The SHA-256 is being computed for
    requirement 1 anyway, so this costs nothing: it is recorded as a duplicate — a third
    category, neither accepted nor rejected by quality — and the bytes are not stored twice.
    """
    suffix = Path(filename).suffix.lower()
    if suffix not in SUPPORTED_SUFFIXES:
        raise DraftError(
            f"{filename}: suffix {suffix!r} is not one of {', '.join(SUPPORTED_SUFFIXES)}"
        )

    freq = int(freq_hz)
    digest = hashlib.sha256(data).hexdigest()

    with _LOG_LOCK:
        log = _frames_log(draft)
        entries = log.setdefault(str(freq), [])

        if any(r["original_filename"] == filename for r in entries):
            raise DuplicateName(
                f"{filename} is already in the {freq} Hz class of this draft — the folder was "
                f"probably dropped twice"
            )

        # Draft-wide, not class-wide: one photograph is one frequency, so the same capture
        # appearing under a second label is a mistake wherever it lands.
        for other in (r for freq_entries in log.values() for r in freq_entries):
            if other["sha256"] == digest:
                _record_duplicate(draft, filename, freq, digest, other)
                raise DuplicateContent(
                    f"{filename} has the same bytes as {other['name']} "
                    f"({other['original_filename']}, {other['freq_hz']} Hz) — it is the same "
                    f"capture uploaded twice, and a repeated frame is not a second observation"
                )

        freq_dir = draft.raw / str(freq)
        freq_dir.mkdir(parents=True, exist_ok=True)
        path = freq_dir / f"IMG_{len(entries) + 1:04d}{suffix}"
        path.write_bytes(data)

        record = {
            "name": path.name,
            "original_filename": filename,
            "freq_hz": freq,
            "quality": QUALITY_PENDING,
            "reason": None,
            "metrics": {},
            "sha256": digest,
            "preview": False,
        }
        entries.append(record)
        log[str(freq)] = sorted(entries, key=lambda r: r["name"])
        _write_frames_log(draft, log)
        return dict(record)


def record_verdict(
    draft: Draft, record: Mapping[str, Any],
    quality: str, reason: str | None, metrics: Mapping[str, Any],
) -> dict[str, Any]:
    """Fill in one live-gate verdict, so a reload does not re-decode six hundred photos.

    An update to the row `store_frame` already wrote, never an insert: the bytes and the verdict
    arrive at different moments and only one of them can be lost.
    """
    freq, name = str(int(record["freq_hz"])), str(record["name"])
    with _LOG_LOCK:
        log = _frames_log(draft)
        updated: dict[str, Any] | None = None
        for row in log.get(freq, []):
            if row["name"] == name:
                row.update(
                    quality=quality,
                    reason=reason,
                    metrics=dict(metrics),
                    preview=preview_path(draft, int(freq), name, "original").exists(),
                )
                updated = row
        if updated is None:
            raise DraftError(f"no frame {name} in the {freq} Hz class of {draft.draft_id}")
        _write_frames_log(draft, log)
        return dict(updated)


def frame_records(draft: Draft, freq_hz: int | None = None) -> list[dict[str, Any]]:
    log = _frames_log(draft)
    if freq_hz is not None:
        return list(log.get(str(int(freq_hz)), []))
    return [r for freq in sorted(log, key=int) for r in log[freq]]


def frame_path(draft: Draft, record: Mapping[str, Any]) -> Path:
    return draft.raw / str(int(record["freq_hz"])) / str(record["name"])


def duplicate_records(draft: Draft) -> list[dict[str, Any]]:
    """Uploads refused for being bytes the draft already has. Kept, not discarded: a retried
    batch is a fact about the afternoon, and the count is what tells you it happened."""
    path = draft.root / DUPLICATES_LOG
    return json.loads(path.read_text("utf-8")) if path.is_file() else []


def size_on_disk(draft: Draft) -> int:
    """Bytes under the draft directory. Three open drafts are a few gigabytes, and whoever has
    to delete one wants to know which."""
    return sum(p.stat().st_size for p in draft.root.rglob("*") if p.is_file())


def _record_duplicate(
    draft: Draft, filename: str, freq_hz: int, digest: str, matches: Mapping[str, Any]
) -> None:
    """Called with `_LOG_LOCK` held."""
    path = draft.root / DUPLICATES_LOG
    entries = json.loads(path.read_text("utf-8")) if path.is_file() else []
    entries.append(
        {
            "original_filename": filename,
            "freq_hz": int(freq_hz),
            "sha256": digest,
            "matches": matches["name"],
            "matches_freq_hz": matches["freq_hz"],
        }
    )
    path.write_text(json.dumps(entries, indent=2, ensure_ascii=False), "utf-8")


def write_previews(
    draft: Draft, path: Path, freq_hz: int, original: np.ndarray, edges: np.ndarray | None
) -> None:
    """Both previews of a rejected frame, from arrays decoded out of `path`.

    `edges` is `None` for a `partial` frame: without four markers there is no rectified plate,
    so there is no edge map that means anything. Showing one anyway would be showing a
    rectification that did not happen.
    """
    target = preview_path(draft, freq_hz, path.name, "original")
    target.parent.mkdir(parents=True, exist_ok=True)
    bgr = (
        cv2.cvtColor(original, cv2.COLOR_RGBA2BGR)
        if original.ndim == 3 and original.shape[2] == 4
        else original
    )
    cv2.imwrite(str(target), thumbnail(bgr, PREVIEW_MAX_SIDE))
    if edges is not None:
        cv2.imwrite(
            str(preview_path(draft, freq_hz, path.name, "edges")),
            thumbnail(edges, PREVIEW_MAX_SIDE),
        )


def preview_path(draft: Draft, freq_hz: int, name: str, kind: str) -> Path:
    return draft.root / "preview" / str(int(freq_hz)) / f"{Path(name).stem}.{kind}.png"


def remove_frame(draft: Draft, freq_hz: int, name: str) -> None:
    """Take one frame back out. The stored names of the frames after it are left alone — they
    are already in `frames.json` and renumbering them would change their `image_id`s."""
    freq = str(int(freq_hz))
    (draft.raw / freq / Path(name).name).unlink(missing_ok=True)
    for kind in ("original", "edges"):
        preview_path(draft, freq_hz, name, kind).unlink(missing_ok=True)
    with _LOG_LOCK:
        log = _frames_log(draft)
        log[freq] = [r for r in log.get(freq, []) if r["name"] != name]
        _write_frames_log(draft, log)


def _frames_log(draft: Draft) -> dict[str, list[dict[str, Any]]]:
    path = draft.root / FRAMES_LOG
    return json.loads(path.read_text("utf-8")) if path.is_file() else {}


def _write_frames_log(draft: Draft, log: Mapping[str, Any]) -> None:
    (draft.root / FRAMES_LOG).write_text(
        json.dumps(log, indent=2, ensure_ascii=False), "utf-8"
    )
```

```python
CALIB_LOG = "calibration.json"


def store_calibration(
    draft: Draft, image_rgba: np.ndarray, cfg: Mapping[str, Any] | None = None
) -> dict[str, Any]:
    """Detect the markers in the calibration frame and, if there are four, keep it.

    `/dades` only ever produces `homography` sessions. `center_crop` is what ingest falls back
    to for a session that was captured without a marker board — a fact about a past afternoon,
    not something to offer as an option while the rig is still set up in front of you. A
    detection that finds three markers is recorded as a failed attempt and calibrates nothing:
    the plate is not rectified, and `docs/02` §6 has every subsequent frame rejected as
    `partial` anyway.
    """
    calib = calibrate(image_rgba, draft.session_id, cfg)
    info = {
        "ok": calib.corners is not None,
        "roi_mode": calib.roi_mode,
        "n_markers": calib.n_markers,
        "marker_ids": calib.marker_ids,
        "corners": calib.corners,
        "px_per_mm": calib.px_per_mm,
        "flags": calib.flags,
    }
    if info["ok"]:
        written = write_calibration(calib, draft.root)
        # `write_calibration` names the file after the session; give it the fixed name the
        # commit will move, so nothing downstream has to reconstruct the session id from a path.
        if Path(written).name != CALIB_LOG:
            Path(written).replace(draft.root / CALIB_LOG)
        draft.log["status"] = STATUS_CALIBRATED

    draft.log["calibration"] = info
    save(draft)
    return info


def calibration(draft: Draft) -> dict[str, Any] | None:
    return draft.log.get("calibration")


def is_calibrated(draft: Draft) -> bool:
    info = draft.log.get("calibration")
    return bool(info and info.get("ok"))
```

### Task 5: Promotion into `data/`, and the guards in front of it

**Files:**
- Modify: `src/drafts.py`
- Test: `tests/test_drafts.py`

**Interfaces:**
- Consumes: `metadata.read_metadata`, `metadata.check_provenance`, `metadata.MixedProvenanceError`.
- Produces:
  - `drafts.existing_rows(data_root, session_id: str) -> int`
  - `drafts.check_provenance_for(data_root, session_id: str) -> None`
  - `drafts.commit_guard(draft, data_root, replace: bool) -> None`
  - `drafts.staging_dir(data_root, session_id: str) -> Path` — `data/raw/.incoming-<session_id>`
  - `drafts.stage(draft, data_root) -> Path` — moves the captures into the staging name
  - `drafts.finish(draft, data_root) -> Path` — renames staging to the session, places the calibration
  - `drafts.discard(drafts_root, draft_id, data_root=None)` — gains the optional root so a
    staged draft's captures go with it

**The property this task exists for.** At any instant, either the draft exists or the session
exists — never a third thing. The commit therefore does not move the captures to their final name
and then ingest them: it moves them to `data/raw/.incoming-<session_id>/`, ingests *there*, and
renames to `<session_id>` only once `ingest_session` has returned. A failure in the middle leaves
a staged draft that says how to resume, and leaves `data/raw/<session_id>` and
`data/calib/<session_id>.json` not existing at all — which matters because `data/calib/` is a
committed directory and an orphan calibration for a session that does not exist would end up in
the repository.

One window is not closed by this and should not be claimed to be: `ingest_session` writes
`metadata.csv` as its last act, so a crash between that write and the rename leaves rows whose
captures are still under the staging name. It is one `os.replace` wide, and the resume path
handles it — `_clear_session_processed` and `replace_session_rows` both key on the session id, so
re-running the commit converges. Say so in the docstring rather than implying atomicity that is
not there.

```python
def existing_rows(data_root: Path | str, session_id: str) -> int:
    path = Path(data_root) / "metadata.csv"
    if not path.is_file():
        return 0
    return sum(1 for r in read_metadata(path) if r["session_id"] == session_id)


def check_provenance_for(data_root: Path | str, session_id: str) -> None:
    """`metadata.check_provenance`, at the door rather than at the commit.

    Finding out that a SYNTH-* session cannot join this dataset before uploading six hundred
    frames is the whole reason this is not left to `ingest_session`.
    """
    path = Path(data_root) / "metadata.csv"
    check_provenance(read_metadata(path) if path.is_file() else [], session_id)


def commit_guard(draft: Draft, data_root: Path | str, replace: bool) -> None:
    """Everything that must be true before a byte of `data/` changes. Raises, never warns.

    `ingest_session` is idempotent, and that is the right default for a command line where
    re-running is what you meant. From a browser it is not: an id typed one digit wrong lands
    on a session someone else captured, and idempotent then means the old rows are gone
    without anyone being asked. So the replacement is offered, not performed.
    """
    root = Path(data_root)
    check_provenance_for(root, draft.session_id)

    if not frame_records(draft):
        raise DraftConflict("this draft has no frames yet")
    if not is_calibrated(draft):
        raise DraftConflict("this draft has no validated calibration")

    rows = existing_rows(root, draft.session_id)
    if rows and not replace:
        raise DraftConflict(
            f"session {draft.session_id} already has {rows} row(s) in metadata.csv. "
            f"Committing replaces every one of them, and the captures under "
            f"data/raw/{draft.session_id} as well. Confirm the replacement or use a "
            f"different session id."
        )


def staging_dir(data_root: Path | str, session_id: str) -> Path:
    """Where a session's captures live between the draft and the session.

    A dotted name, under `data/raw/`, so it is on the same volume as its destination and the
    last step is a rename rather than a copy. `_frames_of` never sees it — ingest is handed the
    path explicitly — and `.gitignore` already excludes all of `data/raw/`.
    """
    return Path(data_root) / "raw" / f".incoming-{session_id}"


def stage(draft: Draft, data_root: Path | str) -> Path:
    """Move the draft's captures under the staging name, with everything ingest will need.

    A move, not a copy: the draft is on the same volume as `data/`, so six hundred 12 MP
    captures change directory in milliseconds. On Windows a cross-volume `os.rename` fails
    outright, which is the second reason the drafts directory is beside `data/` and not in
    `%TEMP%`.

    The `session.json` copied here is the exact file `create` validated, and `calibration.json`
    travels *inside* the staging directory rather than going to `data/calib/`: that directory is
    committed to git, and an orphan calibration for a session whose ingest then failed would be
    a file in the repository describing something that does not exist.
    """
    root = Path(data_root)
    staged = staging_dir(root, draft.session_id)
    if staged.exists():
        # A previous attempt that failed after staging. Its captures are the ones being
        # re-staged, so this is a resume, not a loss — see `dataset_api.commit`.
        shutil.rmtree(staged)
    staged.parent.mkdir(parents=True, exist_ok=True)

    draft.log["status"] = STATUS_COMMITTING
    draft.log["staged"] = True
    save(draft)

    shutil.move(str(draft.raw), str(staged))
    shutil.copyfile(draft.root / SESSION_LOG, staged / SESSION_LOG)
    shutil.copyfile(draft.root / CALIB_LOG, staged / CALIB_LOG)
    return staged


def finish(draft: Draft, data_root: Path | str) -> Path:
    """Rename the staged captures to the session, and place the calibration. Called only after
    `ingest_session` has returned.

    `os.replace` rather than `shutil.move`, because the destination is guaranteed absent by
    `commit_guard` (or emptied by `replace=True`) and a rename within one directory is the
    closest thing to an instant this can be.

    One window remains and is not papered over: `ingest_session` writes `metadata.csv` as its
    last act, so a crash between that write and this rename leaves rows whose captures are still
    under the staging name. Re-running the commit converges — `_clear_session_processed` and
    `replace_session_rows` both key on the session id — and that is the recovery, not a claim
    that the window does not exist.
    """
    root = Path(data_root)
    staged = staging_dir(root, draft.session_id)
    session_dir = root / "raw" / draft.session_id
    if session_dir.exists():
        # Only reachable once `commit_guard(replace=True)` has passed.
        shutil.rmtree(session_dir)

    os.replace(staged, session_dir)

    calib_dir = root / "calib"
    calib_dir.mkdir(parents=True, exist_ok=True)
    shutil.copyfile(session_dir / CALIB_LOG, calib_dir / f"{draft.session_id}.json")

    draft.log["staged"] = False
    save(draft)
    return session_dir
```

```python
"""`/dades` — the routes that put a labelled session into the dataset. `docs/05` §9.

This is the **only** place in the app where a browser causes a write to `data/`, which is why
it is a module of its own rather than more routes in `src/api.py`: §3's serving half still
opens no file after startup, and keeping the two halves apart is what keeps that readable.

Three rules shape every route here:

- **The gate is `ingest.gate_frame`.** Not "the same thresholds as" — the same call. §9: "a
  discrepancy here would let the UI accept images the pipeline rejects."
- **The commit is `ingest.ingest_session`.** The route moves files into place and then calls
  the function `python tasks.py ingest` calls, with the progress hook Task 1 added.
- **No Catalan.** Refusals carry a `code`; the sentence the user reads is chosen in

from __future__ import annotations

import base64
import threading
from pathlib import Path
from typing import Annotated, Any, NamedTuple

import cv2
import numpy as np
from fastapi import APIRouter, File, HTTPException, Query, UploadFile

from calibrate import ROI_MODE_HOMOGRAPHY
from imageio import UnsupportedImageError, decode_bytes, thumbnail
from ingest import IngestError, assess_frame, ingest_session, verdict_of

class DatasetState(NamedTuple):
    data_root: Path
    drafts_root: Path
    calibration_config: dict[str, Any]
    preprocess_config: dict[str, Any]
    gate: dict[str, Any]


def conflict(code: str, message: str, status: int = 409) -> HTTPException:
    return HTTPException(status_code=status, detail={"code": code, "message": message})


def dataset_router(state: DatasetState) -> APIRouter:
    router = APIRouter(prefix="/api")
    jobs_registry: dict[str, Any] = {}

    def load(draft_id: str):
        try:
            return drafts_module.read(state.drafts_root, draft_id)
        except (drafts_module.DraftError, ValueError) as exc:
            raise HTTPException(
                status_code=404, detail={"code": "no_draft", "message": str(exc)}
            ) from exc

    @router.get("/drafts")
    def list_drafts() -> dict[str, Any]:
        return {"drafts": [_summary(d) for d in drafts_module.listing(state.drafts_root)]}

    @router.post("/drafts")
    def new_draft(session_log: dict[str, Any]) -> dict[str, Any]:
        try:
            drafts_module.check_provenance_for(
                state.data_root, str(session_log.get("session_id", ""))
            )
        except MixedProvenanceError as exc:
            raise conflict("mixed_provenance", str(exc)) from exc
        try:
            draft = drafts_module.create(state.drafts_root, session_log)
        except drafts_module.DraftConflict as exc:
            raise conflict("draft_exists", str(exc)) from exc
        except (IngestError, ValueError) as exc:
            raise conflict("invalid_session_log", str(exc), status=422) from exc
        return _detail(draft, state)

    @router.get("/drafts/{draft_id}")
    def get_draft(draft_id: str) -> dict[str, Any]:
        return _detail(load(draft_id), state)

    @router.delete("/drafts/{draft_id}", status_code=204)
    def delete_draft(draft_id: str) -> Response:
        load(draft_id)
        running = jobs_registry.get(draft_id)
        if running is not None and running.status == "running":
            raise conflict("commit_running", "this draft is being committed right now")
        # `data_root` so a staged draft's captures go with it — see `drafts.discard`.
        drafts_module.discard(state.drafts_root, draft_id, state.data_root)
        jobs_registry.pop(draft_id, None)
        return Response(status_code=204)

    return router


def _summary(draft) -> dict[str, Any]:
    records = drafts_module.frame_records(draft)
    return {
        "draft_id": draft.draft_id,
        "session_id": draft.session_id,
        "status": draft.status,
        # The native path, backslashes and all: it is for pasting into a file manager, not
        # for building a URL.
        "path": str(draft.root),
        "created": draft.log.get("created"),
        "updated": draft.log.get("updated"),
        "calibrated": drafts_module.is_calibrated(draft),
        "classes": sorted({r["freq_hz"] for r in records}),
        "total": len(records),
        # Three categories, not two. `accepted` is the gate saying yes; `rejected` is the gate
        # saying no and why; `duplicates` never reached the gate because the draft already had
        # those bytes. Folding duplicates into `rejected` would make a retried upload look like
        # a lighting problem.
        "accepted": sum(1 for r in records if r["quality"] == "ok"),
        "rejected": sum(1 for r in records if r["reason"] is not None),
        "pending": sum(1 for r in records if r["quality"] == drafts_module.QUALITY_PENDING),
        "duplicates": len(drafts_module.duplicate_records(draft)),
        # Three open drafts are a few gigabytes, and whoever has to delete one wants to know
        # which. A walk of the draft directory, not a cached number: a cached one goes stale on
        # the first removal and then lies quietly.
        "bytes": drafts_module.size_on_disk(draft),
    }


def _detail(draft, state: DatasetState) -> dict[str, Any]:
    by_class: dict[str, list[dict[str, Any]]] = {}
    for record in drafts_module.frame_records(draft):
        by_class.setdefault(str(record["freq_hz"]), []).append(record)
    return {
        **_summary(draft),
        "session": draft.session,
        "calibration": drafts_module.calibration(draft),
        "frames": by_class,
        "existing_rows": drafts_module.existing_rows(state.data_root, draft.session_id),
    }
```

```python
#: The calibration preview is the one picture in this view someone squints at, so it gets
#: twice a rejection thumbnail's side and no more.
CALIBRATION_PREVIEW_MAX_SIDE = drafts_module.PREVIEW_MAX_SIDE * 2


def _calibration_preview(pixels: np.ndarray, info: dict[str, Any]) -> str:
    """The frame with the plate quad drawn on it, or the bare frame when there is no quad.

    Drawn on a *display-sized copy*: this picture is for looking at, and the calibration it
    illustrates was computed from the full-resolution array before this function was called.
    The quad is scaled by the same factor the thumbnail used, so what is outlined on screen is
    where the markers actually were.
    """
    bgr = cv2.cvtColor(pixels, cv2.COLOR_RGBA2BGR)
    view = thumbnail(bgr, CALIBRATION_PREVIEW_MAX_SIDE)
    scale = view.shape[1] / bgr.shape[1]
    if info.get("corners"):
        quad = (np.array(info["corners"], np.float32) * scale).astype(np.int32)
        cv2.polylines(view, [quad], isClosed=True, color=(0, 190, 0), thickness=2)
    ok, buffer = cv2.imencode(".png", view)
    if not ok:
        raise RuntimeError("cv2.imencode failed for the calibration preview")
    return base64.b64encode(buffer.tobytes()).decode("ascii")
```

```python
class CommitJob:
    """One commit, running on a thread, with a counter the view can poll.

    Polling rather than a stream, for one reason: requirement 2 says a reload must find the
    session where it was, and a reload drops an `EventSource` too. A number that can be asked
    for again survives what a stream does not, and there is exactly one client on the far side
    of `127.0.0.1`.

    `progress` is called from the worker thread and only ever rebinds two integers; the route
    only ever reads them. No lock, because there is nothing to keep consistent between them —
    a `done` read one frame stale is a progress bar one frame stale.
    """

    def __init__(self, total: int) -> None:
        self.status = "running"
        self.phase = "stage"
        self.done = 0
        self.total = total
        self.report: dict[str, Any] | None = None
        self.error: dict[str, str] | None = None

    def progress(self, done: int, total: int) -> None:
        self.done, self.total, self.phase = done, total, "ingest"

    def as_dict(self) -> dict[str, Any]:
        return {
            "status": self.status, "phase": self.phase, "done": self.done,
            "total": self.total, "report": self.report, "error": self.error,
        }


IDLE = {"status": "idle", "phase": None, "done": 0, "total": 0, "report": None, "error": None}
```

```python
    @router.post("/drafts/{draft_id}/commit", status_code=202)
    def commit(
        draft_id: str,
        replace: bool = False,
        jobs: int | None = Query(default=None, description="worker processes; 1 forces serial"),
    ) -> dict[str, Any]:
        """Step 5. Move, then ingest — and refuse before either if anything is not right.

        Every guard runs on this thread, before the worker starts, so a refusal is an HTTP
        status the view can act on rather than a job that fails somewhere later.
        """
        draft = load(draft_id)
        running = jobs_registry.get(draft_id)
        if running is not None and running.status == "running":
            raise conflict("commit_running", "this draft is already being committed")

        try:
            drafts_module.commit_guard(draft, state.data_root, replace)
        except MixedProvenanceError as exc:
            raise conflict("mixed_provenance", str(exc)) from exc
        except drafts_module.DraftConflict as exc:
            rows = drafts_module.existing_rows(state.data_root, draft.session_id)
            if rows:
                code = "session_exists"
            elif not drafts_module.frame_records(draft):
                code = "no_frames"
            else:
                code = "not_calibrated"
            raise HTTPException(
                status_code=409,
                detail={"code": code, "message": str(exc), "existing_rows": rows},
            ) from exc

        job = CommitJob(total=len(drafts_module.frame_records(draft)))
        jobs_registry[draft_id] = job

        # A draft left `staged` by an attempt that died in the ingest is resumed, not re-staged:
        # its captures are already under the staging name and `draft.raw` no longer exists.
        staged_already = bool(draft.log.get("staged")) and drafts_module.staging_dir(
            state.data_root, draft.session_id
        ).is_dir()

        def work() -> None:
            try:
                staged = (
                    drafts_module.staging_dir(state.data_root, draft.session_id)
                    if staged_already
                    else drafts_module.stage(draft, state.data_root)
                )
                report = ingest_session(
                    draft.session_id, state.data_root, jobs=jobs,
                    progress=job.progress, session_dir=staged,
                )
                # Only now does the session come into being. Everything before this point is
                # recoverable by running the commit again; see `drafts.finish`.
                job.phase = "rename"
                drafts_module.finish(draft, state.data_root)
                job.report = {
                    "session_id": report.session_id, "total": report.total,
                    "accepted": report.accepted, "rejected": report.rejected,
                    "by_reason": report.by_reason, "by_class": report.by_class,
                    "roi_mode": report.roi_mode, "flags": report.flags,
                }
                job.phase, job.status = "finished", "done"
                # The draft has served its purpose and its captures are now in `data/`.
                drafts_module.discard(state.drafts_root, draft_id, state.data_root)
            except Exception as exc:                    # noqa: BLE001 — reported, not swallowed
                job.status = "failed"
                job.error = {"type": type(exc).__name__, "message": str(exc)}

        threading.Thread(target=work, name=f"commit-{draft_id}", daemon=True).start()
        return job.as_dict()

    @router.get("/drafts/{draft_id}/commit")
    def commit_status(draft_id: str) -> dict[str, Any]:
        job = jobs_registry.get(draft_id)
        if job is not None:
            return job.as_dict()
        # No job in this process, but a draft stuck in `committing` means the server was
        # restarted mid-commit. Say so, and say where the files are.
        try:
            draft = drafts_module.read(state.drafts_root, draft_id)
        except (drafts_module.DraftError, ValueError):
            return dict(IDLE)
        if draft.status == drafts_module.STATUS_COMMITTING:
            return {
                **IDLE,
                "status": "interrupted",
                "error": {
                    "type": "Interrupted",
                    "message": (
                        f"the commit of {draft_id} was interrupted. Its captures are staged at "
                        f"{drafts_module.staging_dir(state.data_root, draft_id)} and no session "
                        f"{draft_id} exists yet. Committing again resumes from there; "
                        f"discarding the draft removes the staged captures with it."
                    ),
                },
            }
        return dict(IDLE)

    @router.post("/dataset/split")
```

```python
    @router.get("/dataset/matrix")
    def matrix() -> dict[str, Any]:
        """Images per class per session, and how many sessions cover each class.

        `docs/02` §2 wants every class in at least three sessions; a class in one is a class
        whose test accuracy will be a fact about one afternoon. Seeing that while the rig is
        still set up is the entire point of putting it here rather than only in the curator.

        The numbers are counted, never interpreted: the Catalan sentence about a class being
        short of sessions is chosen in `strings.ts` from `sessions_per_class`.
        """
        path = state.data_root / "metadata.csv"
        rows = read_metadata(path) if path.is_file() else []

        cells: dict[str, dict[str, dict[str, int]]] = {}
        for row in rows:
            freq, session = str(row["freq_hz"]), str(row["session_id"])
            cell = cells.setdefault(freq, {}).setdefault(session, {"total": 0, "accepted": 0})
            cell["total"] += 1
            cell["accepted"] += 1 if is_accepted(row) else 0

        return {
            "sessions": sorted({str(r["session_id"]) for r in rows}),
            "classes": sorted({int(r["freq_hz"]) for r in rows}),
            "cells": cells,
            "sessions_per_class": {freq: len(by) for freq, by in cells.items()},
            "min_sessions_per_class": MIN_SESSIONS,
        }
```

```ts
export class ApiError extends Error {
  constructor(
    message: string,
    readonly status: number,
    /** The machine-readable half of `detail`. Empty when the server sent prose only. */
    readonly code: string = '',
    /** Whatever else the refusal carried — `existing_rows`, for one. */
    readonly info: Record<string, unknown> = {},
  ) {
    super(message)
    this.name = 'ApiError'
  }
}

/** Turn a failed response into an `ApiError`. Exported: `drafts.ts` needs the same parsing,
 *  and two copies of it is exactly the duplication this project keeps refusing. */
export async function apiFailure(response: Response): Promise<ApiError> {
  let detail = response.statusText
  let code = ''
  let info: Record<string, unknown> = {}
  try {
    const body = (await response.json()) as { detail?: unknown }
    if (typeof body.detail === 'string') {
      detail = body.detail
    } else if (body.detail && typeof body.detail === 'object') {
      // §9's routes answer `{code, message, …}` so the Catalan can be chosen in `strings.ts`
      // rather than written in Python.
      const d = body.detail as Record<string, unknown>
      if (typeof d.message === 'string') detail = d.message
      if (typeof d.code === 'string') code = d.code
      info = d
    }
  } catch {
    /* a non-JSON error body is not itself an error worth reporting */
  }
  return new ApiError(detail, response.status, code, info)
}
```

```ts
/**
 * A bounded queue for the one place this app uploads in bulk.
 *
 * Ten classes at sixty frames is six hundred requests, each of which costs the server a
 * ~560 ms HEIC decode. Firing them all at once buries the process; firing them one at a time
 * wastes the wait. Three at a time keeps a verdict arriving every few hundred milliseconds —
 * which is what "you find out that the lighting is wrong on photo three" actually requires —
 * while leaving the tab responsive.
 *
 * A failure is a result, not an end: the eleventh photo being unreadable must not stop the
 * other five hundred and eighty-nine.
 */

export interface QueueOptions<T, R> {
  concurrency?: number
  onResult?: (item: T, result: R | null, error: Error | null) => void
  signal?: AbortSignal
}

export async function uploadQueue<T, R>(
  items: readonly T[],
  worker: (item: T) => Promise<R>,
  { concurrency = 3, onResult, signal }: QueueOptions<T, R> = {},
): Promise<void> {
  let next = 0

  async function drain(): Promise<void> {
    while (next < items.length) {
      if (signal?.aborted) return
      const item = items[next++]
      try {
        const result = await worker(item)
        onResult?.(item, result, null)
      } catch (error) {
        onResult?.(item, null, error instanceof Error ? error : new Error(String(error)))
      }
    }
  }

  await Promise.all(Array.from({ length: Math.min(concurrency, items.length) }, drain))
}
```

```markdown
### Where a session in progress lives

A session being labelled is a **draft**: `drafts/<session_id>/`, at the repo root, outside `data/`
and ignored by git. It holds the uploads exactly as they arrived, the calibration, and one gate
verdict per frame.

That location is the reason "a half-finished session leaves no trace in `data/`" is a property of
the layout rather than a cleanup that has to work. It is also why abandoning a draft is safe to
offer as a button: `DELETE /api/drafts/<id>` removes a directory `data/` never knew about.

Draft state is on the **server**, keyed by the session id, not in the page. Reloading, opening a
second tab or being handed the link finds the session where it was — which is what makes the
BrowserRouter fallback fixed in F6 worth having. `GET /api/drafts` lists what is open, with the
identifier and the full path, so a draft nobody remembers starting can still be found and finished
or discarded.

Committing **moves** the draft's `raw/` tree into `data/raw/<session_id>/` — same volume, so six
hundred captures change directory in milliseconds — writes the session log and the calibration,
and then calls `ingest.ingest_session`, the function `python tasks.py ingest` calls. It runs on a
thread and reports `(done, total)`; the view polls it. At roughly 0.56 s per 12 MP frame, a ten
class session of sixty frames is minutes, not seconds, and nothing about it blocks.

**A session id that already has rows is a question, not a replacement.** `ingest_session` is
idempotent, which is right for a command line; from a browser it is not, because an id typed one
digit wrong would silently replace an afternoon's work. The commit refuses with the row count and
offers the replacement explicitly.

**Calibration comes first, and the server enforces the order.** Uploading a pattern before the
four markers have been found is refused: the 512 px ROI the gate measures does not exist yet.

**The raw bytes arrive raw.** The upload is stored byte for byte — no client-side resize, no
re-encode, no EXIF strip — and every preview is generated from the file after it is stored.
`docs/02` §4 defines `data/raw/` as untouched, straight off the phone, and a recoded JPEG survives
Canny as spurious contours that cannot be spotted in the file afterwards. `tests/test_drafts.py`
asserts the SHA-256 on disk and `web/src/api/drafts.test.ts` asserts the bytes leaving the browser.

**Either the draft exists or the session exists.** The commit does not move the captures to their
final name and then ingest them. It moves them to `data/raw/.incoming-<session_id>/`, ingests
there, and renames to `<session_id>` only once `ingest_session` has returned — so a disk that
fills up or one corrupt capture leaves a staged draft that says how to resume, and leaves nothing
in `data/` answering to the session id. `data/calib/<session_id>.json` is written at that same
last step, because `data/calib/` is committed to git and an orphan calibration for a session that
does not exist would be a file in the repository describing nothing.

**The same capture twice is its own category.** The SHA-256 computed for the paragraph above is
```
