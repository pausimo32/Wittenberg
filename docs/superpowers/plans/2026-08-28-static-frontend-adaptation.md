# Static Frontend Adaptation (A+B) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve the static multipage site from FastAPI on one origin and reconnect its analyser to the real `/api/predict`, so the whole chain runs with no frontend change on the day the real classes are chosen.

**Architecture:** The API is the contract; the frontend adapts to it in one place (`site/js/adapter.js`). The site moves to `site/` so the mount cannot publish `data/`, `runs/` or `src/`. Class metadata stops being hand-written and is generated by `tasks.py modes` from `config/classes.json`.

**Tech Stack:** Python 3.11, FastAPI, Starlette `StaticFiles`, PyTorch (CPU), OpenCV 4.12 contrib, vanilla ES5-style browser JS, `node --test` for the pure mapping functions.

**Spec:** `docs/superpowers/specs/2026-08-28-static-frontend-adaptation-design.md`

## Global Constraints

- `src/preprocess.py` is called by both training and the API and is **never forked**. No task here edits it.
- **Never run the pipeline twice per request** (`docs/05` §3). `quality.assess` currently calls `preprocess_stages` itself; Task 2 makes it accept the already-computed stages instead.
- No `cv2.imshow`, no `plt.show()`, no blocking call.
- Bind `127.0.0.1` only. No CORS middleware, no wildcard, no outbound network call.
- Seed 42 everywhere; deterministic by default.
- Code, comments, commit messages and docs in **English**. UI strings stay **French by default** with the existing `ca`/`es`/`fr` switcher — a deliberate reversal of `CLAUDE.md` rule 6, recorded in ADR 0007 (Task 9).
- No `make`. The task runner is `python tasks.py <target>`.
- No symlinks. `pathlib` over string paths; never hard-code `/`.
- Probabilities are **truncated toward zero**, never rounded up.
- Tests build their own fixtures. `tests/fixtures/` does not exist and is not created.

```python
def write_site_classes(result: Mapping[str, Any], path: Path | str) -> Path:
    """The class list as a browser global, for the static site.

    Written by the same command that writes `config/classes.json` so the two cannot drift.
    Mechanical fields only: everything editorial — the description, the complexity, the
    (m,n) indices — lives in `site/js/frequencies.js`, keyed by frequency, and is written
    by people. The old site hard-coded thirteen frequencies in three places, one of them
    coupled by array position; that is what this replaces.
    """
    entries = [
        {
            "hz": c["freq_hz"],
            "label": f"{c['freq_hz']} Hz",
            "n_nodal_lines": c.get("n_nodal_lines"),
            "symmetry": c.get("symmetry"),
            "width_hz": c.get("width_hz"),
        }
        for c in result["classes"]
    ]
    body = json.dumps(entries, indent=2, ensure_ascii=False)
    text = (
        "/* Generated from config/classes.json by `python tasks.py modes`.\n"
        " * Do not hand-edit: the class index is frozen and this file is regenerated.\n"
        " * Editorial metadata (description, complexity, mode indices) belongs in\n"
        " * frequencies.js, keyed by frequency. */\n"
        f"window.WITTENBERG_CLASSES = {body};\n"
    )
    p = Path(path)
    p.parent.mkdir(parents=True, exist_ok=True)
    p.write_text(text, encoding="utf-8")
    return p
```

`site/js/adapter.js`:

```js
/**
 * adapter.js
 * Wittenberg — Traduction du contrat de l'API vers la forme attendue par l'interface.
 *
 * L'API est la source de vérité (docs/05 §3). Ce fichier est le seul endroit où sa
 * réponse est traduite : le reste de l'interface continue de recevoir la forme qu'il
 * affichait déjà. Un shim /api/v1 côté serveur aurait créé un second contrat à tenir
 * à jour en parallèle du premier, ce que le projet interdit.
 *
 * Fonctions pures, sans DOM : elles sont testées par `node --test tests/js/`.
 */
(function (root, factory) {
  var api = factory();
  root.WittenbergAdapter = api;
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
})(typeof globalThis !== 'undefined' ? globalThis : this, function () {
  'use strict';

  // docs/05 §4 — les trois paliers. Jamais arrondis vers le haut.
  var TIER_HIGH = 0.70;
  var TIER_MID = 0.40;

  function tierOf(p) {
    if (p >= TIER_HIGH) return 'high';
    if (p >= TIER_MID) return 'mid';
    return 'low';
  }

  /** 0,6999 doit se lire « 69,9 % », jamais « 70 % » sous un titre qui dit « peut-être ». */
  function truncatePercent(p) {
    return Math.floor(p * 1000) / 10;
  }

  function formatFrequency(hz) {
    return hz + ' Hz';
  }

  /**
   * L'API ne renvoie pas de libellé : elle renvoie une fréquence entière. Le libellé est
   * fabriqué ici, et `frequencies.js` n'ajoute que l'éditorial, s'il connaît la fréquence.
   */
  function toFrequency(entry) {
    var local = (typeof getFrequencyByHz === 'function') ? getFrequencyByHz(entry.freq_hz) : null;
    var out = {};
    if (local) for (var k in local) if (Object.prototype.hasOwnProperty.call(local, k)) out[k] = local[k];
    out.hz = entry.freq_hz;
    out.label = formatFrequency(entry.freq_hz);
    out.classIndex = entry.class_index;
    out.hasLocalMetadata = Boolean(local);
    return out;
  }

  function mapPrediction(body) {
    var top = (body.top3 || []).slice().sort(function (a, b) { return b.p - a.p; });
    var best = top[0] || null;
    var tier = best ? tierOf(best.p) : 'low';
    var quality = body.quality || { quality: null, reason: null, metrics: {} };

    return {
      success: true,
      tier: tier,
      // Au palier bas, aucun nom en titre : afficher « probablement N Hz » sous 0,35 et
      // le rattraper en petits caractères est exactement la faible confiance masquée
      // que docs/05 §4 interdit.
      leader: tier === 'low' || !best ? null : toFrequency(best),
      runnerUp: tier === 'mid' && top[1] ? toFrequency(top[1]) : null,
      frequency: best ? toFrequency(best) : null,
      confidence: best ? best.p : 0,
      topPredictions: top.map(function (e) {
        return { frequency: toFrequency(e), confidence: e.p };
      }),
      // La géométrie est un état distinct de la confiance : une réponse peu sûre et une
      // réponse mal redressée sont deux échecs différents (docs/05 §4).
      geometry: {
        rectified: body.roi_mode === 'homography',
        roiMode: body.roi_mode,
        markersFound: body.markers_found,
      },
      quality: { quality: quality.quality, reason: quality.reason, metrics: quality.metrics || {} },
      elapsedMs: body.elapsed_ms,
      timings: body.timings_ms || null,
      stages: body.stages || [],
    };
  }

  /** `/api/health` remplace `/api/v1/model-info`. */
  function mapHealth(health) {
    if (!health) return { available: false, status: 'unreachable', reachable: false };
    return {
      available: true,
      status: 'ready',
      reachable: true,
      modelName: health.model,
      modelVersion: health.model_run,
      preprocessingVersion: health.preprocess_version,
      device: health.device,
      classes: health.classes || [],
      synthetic: Boolean(health.synthetic),
      // null quand les chiffres du run sont citables. Le bandeau disparaît de lui-même
      // le jour où un vrai checkpoint remplace le checkpoint synthétique.
      doNotReport: health.do_not_report || null,
    };
  }

  return {
    TIER_HIGH: TIER_HIGH,
    TIER_MID: TIER_MID,
    tierOf: tierOf,
    truncatePercent: truncatePercent,
    formatFrequency: formatFrequency,
    mapPrediction: mapPrediction,
    mapHealth: mapHealth,
  };
});
```
