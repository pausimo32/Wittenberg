Méthodologie de collecte

Protocole d'acquisition

  • Position de caméra fixe, perpendiculaire à la plaque
  • Hauteur de caméra identique pour chaque session
  • Éclairage diffus uniforme (éviter les reflets)
  • Masse de sel identique : 2,0 g ± 0,1 g
  • Durée d'exposition : ≥ 30 secondes par fréquence
  • Fond de plaque uni et mat (noir ou blanc)

Étiquetage & nomenclature

  • Fichier nommé : chladni_{Hz}_{idx:04d}.jpg
  • Ex. : chladni_660_0001.jpg
  • Dossier par classe : dataset/660hz/
  • Métadonnées CSV associées : fréquence, date, conditions
  • Vérification visuelle systématique de chaque image

Prétraitement avant entraînement

  • Redimensionnement : 224 × 224 pixels
  • Conversion en niveaux de gris (1 canal)
  • Normalisation des pixels : [0, 1]
  • Augmentation de données : rotations ±15°, flips horizontaux
  • Soustraction de la moyenne de l'ensemble d'entraînement

Métriques d'évaluation

  • Précision globale (accuracy) sur jeu de test
  • Matrice de confusion par classe de fréquence
  • F1-score par classe (gestion des déséquilibres)
  • Courbe d'apprentissage (loss / accuracy par époque)
  • Analyse des erreurs sur les classes ambiguës

Visualisation des modes (simulation)

Ces motifs sont générés mathématiquement à titre d'illustration. Les motifs réels produits sur la plaque expérimentale différeront selon le matériau, la forme de la plaque et les conditions acoustiques.

Pipeline d'entraînement (cible)

Architecture CNN cible :
Conv2D(32, 3×3) → ReLU → MaxPool → Conv2D(64, 3×3) → ReLU → MaxPool → Conv2D(128, 3×3) → ReLU → MaxPool → Flatten → Dense(256) → Dropout(0.4) → Dense(13, softmax)

Framework : TensorFlow / Keras (Python) — puis export TensorFlow.js pour intégration navigateur
Optimiseur : Adam (lr = 0.001) — réduction sur plateau
Loss : Categorical Crossentropy
Métriques : Accuracy, F1-score par classe
